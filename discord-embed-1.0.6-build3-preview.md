### Xneon Launcher 1.0.6 — третий билд: производительность, стабильность и просмотр элитры. Скачать по ссылкам ниже, отчёты о багах — в канал багов.

Полный ченджлог — по ссылке ниже.

**Исправлено**
• Сервер запускается, даже если Java не установлена — рантайм скачивается автоматически, как при запуске Minecraft.
• Правки сборки (Java, память, команды, группа) больше не теряются при сохранении.
• Список сборок больше не «выгружается» и не грузится заново; вместо чёрного экрана — скелет загрузки, а ошибка страницы не роняет лаунчер.
• Dropbox-авторизация больше не отваливается через ~4 часа.
• `.litemod` снова виден в списке модов сборки (раньше пропадал после пересканирования).
• Статистика удалённых серверов больше не висит в «Активности».
• Плащ больше не пропадает с превью персонажа при загрузке нового скина.
• Установленный мод в каталоге помечен «Установлен» и не предлагается повторно — в том числе как зависимость и на второй площадке.

**Добавлено**
• Кнопка «Элитра» в превью скинов: персонаж разворачивается спиной, и видно, как плащ ложится на элитру.
• Пагинация в списке установленных модов — по 20 штук на страницу вместо простыни из сотен карточек.

**Производительность**
• Открытие сборки больше не морозит интерфейс: разбор JAR ушёл в отдельный поток (149 модов ≈ 4 с, интерфейс живой).
• Переходы по вкладкам стали заметно быстрее — тяжёлые страницы подгружаются только там, где это оправдано.
• Список сборок читается лёгким запросом вместо мегабайтов JSON (в 70 раз быстрее).
• Скриншоты и размеры миров кэшируются; повторное открытие вкладки не перечитывает файлы.
• Консоль сервера и страница логов не тормозят на больших объёмах.
• Определение установленных Java кэшируется — поиск больше не запускается заново на каждый экран.

**Безопасность и надёжность**
• Пути файлов сервера проверяются надёжнее: выход за папку сервера и в соседние каталоги закрыт.
• Локальные изображения читаются только из папки скинов лаунчера.
• Облачные токены хранятся и обновляются единообразно во всех шести провайдерах.
• Схема БД версионируется — обновление проходит быстрее и без лишних проверок.

**Что проверить**
1. Сервер: удалить все Java (или взять версию без подходящей) → запустить сервер → рантайм должен скачаться сам и сервер стартовать.
2. Сборки: изменить память/Java/группу → перезапустить лаунчер → правки на месте.
3. Сборки: походить по вкладкам и вернуться — список не должен исчезать и грузиться заново.
4. Моды: открыть сборку на 150+ модов — список с пагинацией, `.litemod` виден.
5. Скины: загрузить скин в библиотеку → выбрать плащ → нажать «Элитра» → персонаж со спины с крыльями.
6. Скриншоты: открыть вкладку дважды — второй раз открывается мгновенно (кэш).
7. Dropbox: подключить и проверить, что через несколько часов авторизация держится.
