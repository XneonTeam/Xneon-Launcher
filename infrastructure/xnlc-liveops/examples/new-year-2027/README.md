# New Year 2027

`new-year-2027.xntheme` — обычный экспортируемый формат Custom Themes:
ZIP с `theme.json` (`format: "xneon-theme"`, `version: 1`, объект `theme`).
Весь CSS, SVG-фон зимнего города, снег и палитра находятся внутри архива.
В коде лаунчера нет ни ID этой темы, ни её стилей. Сетевые ресурсы не требуются.
Архив также можно импортировать обычным импортом тем для ручного просмотра.

`campaign.json` описывает отдельное тестовое расписание, а не включается
автоматически в production-каталог:

- campaign ID: `new-year-2027-test-xmas-gold`;
- theme ID внутри архива: `new-year-2027`;
- Asia/Yekaterinburg: 15.11.2026 **[18:30:48, 19:30)**;
- UTC: **[13:30:48, 14:30)**.

Загрузка — существующим `themesvc put` с `--file new-year-2027.xntheme`,
`--id new-year-2027-test-xmas-gold`, `--start 2026-11-15T18:30:48+05:00` и
`--end 2026-11-15T19:30:00+05:00`, указав адрес сервиса и его token-file.
По запросу пользователя кампания загружена на `http://127.0.0.1:8091`;
локальный deployment root — `infrastructure/xnlc-liveops/deploy/local-new-year-2027/`.
Сервер привязан только к loopback; после 19:30 кампания становится недоступной.
Christmas-оформление без общей голубой обводки полей опубликовано с новым ID
по явному разрешению пользователя. Прежние кампании завершены/отозваны;
ID самой темы и время начала сохранены, окончание продлено до 19:30 по запросу.
Хеш пакета вычислен сервером при загрузке.

При доставке LiveOps использует собственный `event:<campaignId>` и `custom: false`;
при обычном пользовательском импорте архив становится Custom Theme.
