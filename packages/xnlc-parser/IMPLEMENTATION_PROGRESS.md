# Ход реализации

- A: проверка потребления DEFLATE, секции manifest, отдельная схема Bungee, диагностика неверных деклараций, четыре вида паков, сквозная отмена и структурная проверка иконок. Проверка иконок не декодирует пиксели; APNG и animated WebP отклоняются. Изменённые файлы: archive.ts, metadata.ts, directory.ts, image.ts, utilities.ts, index.ts и регрессионные тесты.
- B, частично: общий для дерева архивов счётчик попыток и объявленных сжатых байтов, предел одновременных чтений, дедлайн worker, весовой LRU и singleflight с независимой отменой подписчиков. Переиспользование worker приводило к зависанию последовательной задачи на Bun 1.4.4; сохранён отдельный поток на задачу. Изменены archive.ts, worker.ts, cache.ts и их тесты.
- Адаптер лаунчера учитывает новые типы паков при выборе metadata мода.
- Следующий шаг: минимальный независимый тест повторной доставки сообщений worker, затем транспорт с проверяемым завершением и ограниченным пулом. После этого — закреплённый файловый handle, структурные лимиты парсеров и общий бюджет между задачами.
- C–G не завершены: ZIP64/CP437/Unicode Path, расширенные форматы, resolver/JVM, сопоставимый benchmark, CI и fuzzing. Существующие строгие отказы ZIP сохранены.
- Проверки: build с TypeScript-декларациями и полный пакетный набор с сетевыми fixtures — 101 pass, 0 fail на Windows/Bun 1.4.4. Реальный Quilt fixture подтвердил необходимость поддержки структуры versions.all; она сохранена без заявления о разрешении диапазона.
