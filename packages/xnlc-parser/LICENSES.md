# Лицензии и зависимости

- Код пакета распространяется под [MIT](LICENSE), как соседние пакеты `@xnlc`. Корневой проект лаунчера имеет собственную лицензию GPL-3.0; лицензия пакета её не заменяет.
- У пакета нет npm-зависимостей времени выполнения. Нужен Bun: используются встроенные `Bun.TOML`, `Bun.YAML`, `Bun.hash.crc32`, `Bun.CryptoHasher` и совместимые API `node:fs`, `node:stream`, `node:zlib`. Отдельный Node.js runtime не нужен. [Лицензионный файл Bun](https://github.com/oven-sh/bun/blob/main/LICENSE.md) указывает MIT для самого Bun и отдельные условия включённых компонентов, включая JavaScriptCore; при распространении runtime необходимо учитывать его уведомления.
- Тесты и benchmark собирают фикстуры через общий ZIP-хелпер на `fflate` 0.8.x, [MIT](https://github.com/101arrowz/fflate/blob/master/LICENSE); тот же движок использует продуктовая распаковка.
- Сетевые тесты обращаются к Modrinth и зафиксированному тестовому вектору Aternos; JAR сторонних авторов в пакет не включены. У каждого мода собственные условия распространения.
- Код modcrawl и XMCL не включён как зависимость или копия. Пакет использует
  `@xnlc/archives`; его ZIP-кодек fflate распространяется по MIT. Уведомления
  включённых библиотек сохраняются при публикации и упаковке.
