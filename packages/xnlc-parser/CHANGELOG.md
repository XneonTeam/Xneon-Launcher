# Изменения

## 1.0.0

- XNLC — единственный движок сканирования модов. Локальный кэш обновляется при смене версии пакета.

- ZIP: отклоняется хвост внутри объявленного DEFLATE; неуспешные чтения расходуют квоту попыток и сжатых байтов.
- Metadata: версия только из главной секции manifest, зависимости Bungee, диагностика форм деклараций и структурное различение паков.
- API: `PackFormat`, `probeImage`, отдельный сигнал `ArchiveContext.read`, `TIMEOUT` worker. `extractIcon` больше не принимает один magic header. Исчерпывающие switch по `Format` требуют новых веток.
- Cache: лимит приблизительного веса, статистика вытеснений, дедупликация одновременных запросов.
