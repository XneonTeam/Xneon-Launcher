# Сканирование модов

Лаунчер импортирует API @xnlc/parser 1.0.0 напрямую. Пакет разбирает архивы, извлекает метаданные и требования загрузчиков, сравнивает диапазоны и управляет очередью параллельного сканирования. Лаунчер задаёт путь к упакованному worker, сообщает прогресс, сохраняет результаты в SQLite и возвращает их через IPC. Повреждённые архивы дают частичный результат с диагностикой.

Версия кэша локальных метаданных привязана к версии пакета. Индексы Modrinth и CurseForge при просмотре и импорте читаются через `ArchiveContext`; извлечение файлов, создание ZIP и независимые серверные операции сохраняют свои средства работы с архивами.
