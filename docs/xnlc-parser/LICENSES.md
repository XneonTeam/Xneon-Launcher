# Лицензии и использование исходников

Статус: предварительная проверка, не полный аудит dependency tree и не юридическое заключение.

| Компонент | Данные из исходников | Решение |
|---|---|---|
| modcrawl 0.14.0 | `Cargo.toml` и `LICENSE`: MIT | Идеи можно изучать; при копировании сохранять требуемые MIT уведомления. |
| zipcrawl 4.0.1 | `Cargo.toml`: MIT; использует crate `zip` | Лицензию точной версии `zip` и её транзитивных зависимостей ещё проверить. |
| XMCL / mod-parser 3.4.3 | корневой LICENSE и package manifest: MIT | Независимая реализация предпочтительна; при копировании соблюдать условия MIT. |
| `@xmcl/asm` 1.0.1 | manifest MIT; `libs/ClassReader.ts` содержит дополнительное уведомление INRIA/France Telecom в стиле BSD-3-Clause | При переносе кода необходимо сохранить соответствующие уведомления и ограничения; название пакета MIT не отменяет заголовки исходников. |
| `@xmcl/system` 2.3.0 | manifest MIT; использует `@xmcl/unzip`, `@xmcl/yauzl`, `jszip` | Проверить точные версии и лицензии в lockfile до использования. |
| `smol-toml`, `toml`, YAML, DEFLATE/ZIP | Используются в исследуемых деревьях; лицензии и транзитивные условия здесь не проверены | Выбрать точные версии и проверить лицензии/уведомления до добавления зависимости. JSON — встроенный runtime parser. |

Идея и независимая реализация отличаются от копирования выраженного кода. Использование пакета как зависимости требует соблюдения его лицензии и лицензий поставляемых транзитивных компонентов. Проект ещё не выбрал зависимости нового parser; полный список лицензий нельзя считать готовым.
