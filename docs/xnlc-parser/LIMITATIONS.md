# Ограничения и открытые вопросы

- Аудит не охватил полностью все loader handlers, `zip` и `java-class-rs`, тесты, историю изменений и все транзитивные лицензии. Выводы об отсутствии функций ограничены просмотренными модулями.
- Не выполнены независимые fingerprint-векторы и проверка реального значения CurseForge API; ранее найденное совпадение описаний не заменяет такой тест.
- Сохранение Quilt `unless` и альтернатив требует AST и спецификационных тестов. Универсальный semver не гарантирует корректность диапазонов всех загрузчиков.
- Название вложенного JAR не доказывает удовлетворение зависимости; metadata могут отсутствовать или быть повреждены.
- Mixin target overlap и одинаковое имя класса — признаки для исследования, не доказательство конфликта. Multi-release JAR, затенение библиотек и порядок загрузки усложняют выводы.
- Class-level annotations не заменяют анализ инструкций, используемый частью эвристик XMCL. Паритет legacy Forge нельзя заявлять без реальных fixtures.
- Объединение metadata, icon, hash и full class analysis увеличивает объём работы; benchmark должен разделять сценарии. Ни один runtime, версия или порог RSS не проверены измерением.
- Директории ресурсов и шейдеров, данные UI и БД, fallback и worker-протокол — обязательные условия будущей интеграции.
- Не реализованы библиотека, адаптер, тесты и benchmark; предложенная архитектура предварительна.
