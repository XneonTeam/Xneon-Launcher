# Первый запуск на macOS Apple Silicon

Экспериментальная ARM64-сборка распространяется без Developer ID и без
нотариализации Apple. Платная Apple Developer Program не используется.
macOS может показать предупреждение или заблокировать первый запуск.

1. Скачайте DMG или ZIP только из официального репозитория Xneon Launcher.
2. Сверьте SHA-256 с `SHA256SUMS.txt` того же набора артефактов. Контрольная сумма
   проверяет целостность файла, но **не заменяет Code Signing или Notarization**.
3. Откройте DMG либо распакуйте ZIP и попробуйте открыть приложение.
4. Если Gatekeeper заблокировал запуск, откройте «Системные настройки →
   Конфиденциальность и безопасность → Открыть всё равно» и подтвердите запуск
   именно этого приложения. Разрешайте его только если доверяете источнику.

Не отключайте Gatekeeper целиком. Не требуется выполнять `spctl --master-disable`
или рекурсивно снимать quarantine со всех загрузок.

Если macOS сообщает о повреждённом приложении, сначала повторно проверьте
контрольную сумму. Сохраните точный текст ошибки для отчёта; не предполагайте,
что любая такая ошибка вызвана только отсутствием подписи.

CI-запуск незакварентиненного приложения не доказывает, что скачанный через браузер
файл пройдёт Gatekeeper. Этот сценарий проверяется отдельно на пользовательском Mac.
