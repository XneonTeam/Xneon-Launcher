Логотипы Anthropic, Google Gemini и Ollama взяты из [Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons): `anthropic.svg`, `googlegemini.svg`, `ollama.svg`.

Лицензия коллекции: [CC0 1.0 Universal](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). Логотипы используются для обозначения соответствующих провайдеров.

В интерфейсе SVG служат маской: цвет наследуется от текста, включая выбранный пункт и светлую тему. Файлы включаются в сборку и не требуют сети.

Иконки моделей определяются по каталогу https://models.dev/api.json. Порядок поиска: каноническая модель, подтверждённое семейство, точная запись внутри явно указанного пространства имён сервиса, известный провайдер в префиксе. Глобального поиска разработчика по непроверенным именам посредников нет.

Семейства строятся по уникальным каноническим ID. Если канонических данных нет, требуется версионированное имя и подтверждение через family или имя разработчика. Категория маршрутизации и случайное совпадение названия доказательством не считаются. При спорных данных остаётся общая иконка. Списков исключений для названий моделей или маршрутизаторов нет.

Логотипы загружаются с models.dev. Имя файла уточняется по зарегистрированным провайдерам каталога. Для разработчика без подходящего файла запрашивается публичный аватар организации через Hugging Face; цветные аватары не инвертируются. Одновременные запросы объединяются по разработчику.

Индекс кэшируется на сутки. Изменения алгоритма меняют версию кэша, поэтому старые предположения о разработчиках не переносятся в новый индекс.
